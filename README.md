# ml-projects

AI/ML projects, each in its own folder with its own README, tests and CI workflow. Code is MIT licensed (see [LICENSE](LICENSE)). Each project's README describes how that project was built.

| Project | Description |
|---|---|
| [hospital-readmission-risk](hospital-readmission-risk/) | Predicts the probability that a diabetic inpatient encounter is readmitted within 30 days, from information available at discharge. Compares logistic regression, decision tree, random forest, XGBoost and a neural network, and serves the chosen model through a tested web app with a [live demo](https://readmission-app-364492331058.us-central1.run.app). Start with the [project report](hospital-readmission-risk/docs/PROJECT_REPORT.md). |
